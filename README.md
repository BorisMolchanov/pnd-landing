# Трубы ПНД и гофра оптом — концепт лендинга

Концепт продающего B2B-лендинга компании «Строй Страна»: трубы ПНД, гофрированные трубы и фитинги напрямую с завода-изготовителя. Аудитория — снабженцы и инженеры строительных и монтажных компаний, водоканалов, генподрядчиков и госзаказчиков; трафик — Яндекс.Директ.

**Обновлено 12.11.2026:** тексты от лица «Строй Страны», каталог без остатков и цен, окно «Запросить прайс», одна форма заявки, блоки «Как работаем», «Пять ошибок при выборе трубы ПНД», FAQ и финальный экран, подмена заголовка под ключевую фразу, цели Метрики, локальные шрифты. Подробности — в разделе «Текущая модель» в [`docs/structure.md`](docs/structure.md).

**Живая версия:** https://borismolchanov.github.io/pnd-landing/

## Перед запуском рекламы

1. **Подключить формы.** Сейчас обе формы (заявка и «Запросить прайс») показывают демо-сообщение. Подключите их к CRM (Bitrix24, amoCRM) или обработчику на российском сервере: по 152-ФЗ персональные данные россиян сначала записываются в базу на территории РФ. В заявку уходят поля `spec` (файл), `contact`, `city`, `items` (позиции из каталога), `consent`.
2. **Подключить Яндекс Метрику.** Впишите номер счётчика в `METRIKA_ID` в начале [`assets/app.js`](assets/app.js) и создайте в Метрике цели типа «JavaScript-событие»: `lead_submit`, `spec_upload`, `price_request`, `kp_send`, `phone_click`, `email_click`. Про Метрику и cookie нужно написать в политике обработки персональных данных.
3. **Политика обработки персональных данных** — отдельная страница; согласие оформляется отдельно от других документов. Ссылку поставить вместо `[ссылка]` в футере и в формах.
4. **Свой домен.** Например, `pnd.stroi-strana.ru` вместо github.io.
5. **Убрать плашку «Концепт-макет»** и заменить заглушки в [квадратных скобках].

## Подмена заголовка под ключевую фразу

В ссылке объявления Директа добавьте `?utm_term={keyword}`. Скрипт берёт из фразы только товарную группу (труба ПНД, гофра для канализации, гофра для кабеля, фитинги) и диаметр из стандартного ряда — «труба пнд 110 купить» превращается в «Трубы ПНД Ø110 мм с завода-изготовителя — дешевле заводского прайса», и в каталоге открывается нужная вкладка. Произвольный текст из адреса на страницу не попадает.

## Важно знать

- **Цена — «до 30% ниже прайса завода».** В каталоге цен нет: точная цена — в КП.
- **Наличие в каталоге — ориентир** («обычно в наличии» / «под заказ»), без остатков и дат: их некому поддерживать в актуальном виде.
- **Масса 1 м** — расчётная по ГОСТ 18599-2001 (средняя толщина стенки, плотность 950 кг/м³). Ассортимент (диаметры, SDR, гофра ПП, кабельная 450/750 Н) нужно сверить с заводом.
- **Заглушки в [скобках]:** реквизиты, адрес офиса, ссылка на политику, верхняя граница диаметров, срок КП, условия договора и НДС, минимальная партия, фото.
- **Страница закрыта от индексации** (`noindex`). Для рекламных лендингов это нормально; особенно если будут похожие региональные версии — запрет защищает от дублей в поиске.
- **Труба на первом экране — векторная иллюстрация.** Её можно заменить 3D-рендером по ТЗ из `docs/ui-guidelines.md`; фото-заглушки — реальная съёмка производства с разрешения завода.
- **Внутренние данные — в `private/`.** Папка исключена из git и есть только локально. Рабочие заметки и материалы заказчика держите там, а не в `docs/`.

## Как включить GitHub Pages

1. В репозитории откройте **Settings → Pages**.
2. В поле **Source** выберите **Deploy from a branch**.
3. Ветка `main`, папка `/ (root)` → **Save**.
4. Через 1–2 минуты сайт откроется по адресу из начала этого файла.

Посмотреть локально: откройте `index.html` в браузере.
