# Трубы ПНД и гофра оптом — концепт лендинга

Концепт продающего B2B-лендинга поставщика труб ПНД, гофрированных труб, фитингов и сварочного оборудования напрямую с завода-изготовителя. Аудитория — снабженцы и инженеры строительных и монтажных компаний, водоканалов и генподрядчиков; трафик — Яндекс.Директ.

**Обновлено 05.11.2026** по голосовому описанию поставщика: модель «свой склад» заменена на «поставщик с заводом-изготовителем», добавлены факты о ценах, сроках, сервисе и опыте поставок. Подробности — в разделе «Обновление» в [`docs/structure.md`](docs/structure.md).

**Живая версия:** https://borismolchanov.github.io/pnd-landing/ (появится после включения GitHub Pages, см. ниже)

## Важно знать

- **Цифры в [квадратных скобках] — заглушки.** Перед запуском замените их реальными данными компании. Масса 1 м в каталоге — ориентировочная, берите значения из таблицы ГОСТ 18599-2001.
- **Формы не отправляют данные.** GitHub Pages — статический хостинг. Для рабочей версии подключите формы к CRM (amoCRM, Bitrix24) или обработчику на российском сервере: по 152-ФЗ персональные данные россиян сначала записываются в базу на территории РФ.
- **Страница закрыта от индексации** (`<meta name="robots" content="noindex">`), чтобы концепт с заглушками не попал в поиск. Для боевой версии уберите этот тег.
- **Скидка «−[N]%» к прайсу завода — заглушка.** 20–35% из описания поставщика — это закупочная скидка; клиентскую цену определяет владелец.
- **Труба на первом экране — векторная заглушка.** Её заменяет 3D-рендер по ТЗ из `docs/ui-guidelines.md`, фото-заглушки — реальная съёмка производства (без логотипа завода, пока его название не публикуется).

## Как включить GitHub Pages

1. В репозитории откройте **Settings → Pages**.
2. В поле **Source** выберите **Deploy from a branch**.
3. Ветка `main`, папка `/ (root)` → **Save**.
4. Через 1–2 минуты сайт откроется по адресу из начала этого файла.

Посмотреть локально: откройте `index.html` в браузере.
